# CareerPilot

CareerPilot is a backend project focused on helping students with their career and placement preparation.

The project is currently under development. I am building it step by step while learning Spring Boot, REST APIs, JPA, and database integration.

## Current Progress

At the moment, the project includes:

* Spring Boot backend setup
* Maven project configuration
* PostgreSQL database integration
* JPA/Hibernate configuration
* Initial User entity
* Initial backend project structure
* HTTP API testing setup

## Tech Stack

* Java
* Spring Boot
* Spring Data JPA
* Hibernate
* PostgreSQL
* Maven
